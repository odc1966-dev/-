# 클로드 코드 마스터리 12주

클로드 코드(Claude Code)를 "쓸 줄 아는" 수준에서 "설계 의도를 설명하고 남에게 전수하는" 수준까지
끌어올리기 위한 12주 커리큘럼. 공식 문서(https://code.claude.com/docs/ko) 150여 편을
Phase 0~7로 재배열하고, 각 학습 단위에 **통과 기준**과 **재현 가능한 실험**을 붙였다.

## 구성

| Phase | 기간 | 주제 |
|---|---|---|
| 0 | D-3 | 실험실 세팅 — 측정 장치를 먼저 만든다 |
| 1 | 1–2주 | 에이전틱 루프와 도구 표면 |
| 2 | 3–4주 | 컨텍스트 엔지니어링 (L2 → L4의 분기점) |
| 3 | 5–6주 | 확장 레이어 — skill · subagent · hook · MCP · plugin |
| 4 | 7–8주 | 병렬 실행과 오케스트레이션 |
| 5 | 9–10주 | 헤드리스 · CI · Agent SDK |
| 6 | 11–12주 | 해부 — 세션 로그 파싱, 토큰 회계, 변경 로그 역주행 |
| 7 | 13주~ | 전수 — 배포 · 강의 · 최신 유지 |

## 이해의 다섯 층위

L1 조작 → L2 구성 → L3 확장 → **L4 해부** → **L5 전수**.
대부분 L2에서 멈춘다. L4·L5는 문서 독해가 아니라 측정과 산출물로만 도달한다.
