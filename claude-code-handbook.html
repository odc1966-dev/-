클로드 코드 레퍼런스 자료집

커리큘럼이 무엇을 어떤 순서로 할지 정한다면, 이 자료집은 그때마다 펼쳐 보는 내용입니다. 표는 전부 공식 문서에서 확인한 실제 값이고, 검색창은 모든 표를 한꺼번에 훑습니다.

문서 색인

공식 문서 150여 편을 학습 순서가 아니라 찾기 좋은 순서로 묶었습니다. 커리큘럼의 Phase 순서가 필요하면 커리큘럼 쪽을 보세요.

모든 표는 공식 문서(code.claude.com/docs)에서 확인한 값입니다. 기능은 주 단위로 바뀌므로, 값이 문서와 다르면 문서가 맞습니다. 릴리스 워치 Routine이 매주 변경분을 잡아 다이제스트로 남깁니다.
