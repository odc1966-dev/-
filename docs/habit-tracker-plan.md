# 습관 기록 앱 기획서

WhatsApp의 Instinct 비서에게 "운동했어"라고 말하면 구글 시트에 기록되고, 앱에서 통계와 목표 달성을 확인한다.

## 1. 확정된 요구사항 (인터뷰 결과)

| 구분 | 내용 |
|---|---|
| 사용자 | 본인 1명 |
| 목표 | 운동 주 2회, 독서 주 2회, 책 완독 올해 3권 |
| 측정 | 횟수만 센다 (시간·분량은 기록하지 않음) |
| 통계 | 주간·월간·연간, 내 과거 평균과 비교 |
| 확인 | 상세는 앱, 간단한 질문은 WhatsApp |
| 수정 | 앱에서 기록 수정·삭제 |
| 알림 | 수·토 저녁 주간 시행 횟수, 월요일 08:00 지난주 요약 |
| 주 시작 | 월요일 |

## 2. 구조

```
WhatsApp ──"운동했어"──▶ Instinct ──한 줄 추가──▶ 구글 시트 "습관기록"
                                                    ▲
                           앱(대시보드) ──읽기·수정──┘
```

- 원본 기록은 구글 시트 하나뿐이다. 비서를 바꿔도 앱은 그대로 쓴다.
- Instinct의 시트 쓰기는 2026-10-06 테스트에서 확인했다.
- 알림은 Instinct에 설정했다(2026-10-06). 첫 발송 예정은 2026-10-07(수) 20:00이며, 실제로 오는지는 아직 확인하지 않았다.

## 3. 시트 구조

**기록 탭**: Instinct가 한 번에 한 줄씩 추가한다.

| 날짜 | 항목 | 수치 | 단위 | 메모 |
|---|---|---|---|---|
| 2026-10-06 | 운동 | 60 | 분 | |
| 2026-10-07 | 독서 | 1 | 회 | |
| 2026-10-20 | 책 완독 | 1 | 권 | 책 제목 |

- Instinct가 이미 이 5열 형식으로 쓰고 있어 그대로 둔다. 앱은 수치·단위를 무시하고 행 수로 횟수를 센다.
- 항목명은 `운동`, `독서`, `책 완독` 세 개로만 적는다. 표기가 다르면 집계에서 빠진다.

**목표 탭**: 처음에 한 번 입력하고, 목표가 바뀔 때만 고친다.

| 항목 | 주기 | 목표횟수 |
|---|---|---|
| 운동 | 주 | 2 |
| 독서 | 주 | 2 |
| 책 완독 | 연 | 3 |

- D열 `올해 기존`: 시트를 쓰기 전에 이미 달성한 횟수. 연 목표에만 더한다(책 완독 2). 매년 1월에 0으로 바꾼다.

## 4. 집계 규칙

- 운동과 독서는 하루에 여러 번 기록해도 **1회**로 센다.
- 책 완독은 기록 한 줄을 한 권으로 센다.
- 주간 목표 달성은 그 주(월~일) 횟수가 목표 이상인 경우다.
- 평균 비교의 기본 기준은 **직전 4주 평균**이고, 월간·연간은 지난달·작년과 비교한다.
- 연간 책 목표는 진도선을 함께 보여준다. 예를 들어 10월 초라면 기대치는 3권 × (경과일/365)이다.

## 5. 화면 구성

| 화면 | 내용 |
|---|---|
| 홈 | 이번 주 운동 ●●○ / 독서 ●○○ 진행 표시, 올해 책 n/3권, 연속 달성 주 수 |
| 달력 | 월 달력에 항목별 색 점 표시 |
| 통계 | 주·월·연 탭. 달성률, 횟수 막대그래프, 평균 대비 ↑↓ |
| 기록 | 최근 기록 목록. 눌러서 수정·삭제 |

## 6. 기술 선택

**추천: 구글 Apps Script 웹앱** (시트에 붙어 있는 작은 프로그램을 웹 화면으로 여는 방식)

| 방식 | 장점 | 단점 |
|---|---|---|
| Apps Script 웹앱 (추천) | 서버·호스팅이 필요 없다. 구글 로그인과 시트 수정 권한이 자동으로 처리된다. HTML 한 파일로 만들 수 있다 | 정식 PWA가 아니어서 홈 화면 바로가기로만 쓴다. 첫 로딩이 1~3초 걸린다 |
| Next.js PWA | 앱처럼 설치되고 빠르다 | Google Cloud에 OAuth 설정을 해야 하고, 호스팅이 필요하며, 로그인이 가끔 풀린다 |

혼자 쓰는 앱이고 앱에서 시트를 수정해야 하므로 설정 부담이 가장 적은 Apps Script로 시작한다. 나중에 PWA로 옮겨도 시트는 그대로 쓸 수 있다.

## 7. 개발 순서

1. 시트를 정리한다. 기록·목표 탭을 만들고 Instinct에게 기록 규칙을 지시한다.
2. 알림이 실제로 오는지 확인한다(첫 발송 10/7 수 20:00). 오지 않으면 Apps Script의 시간 트리거(정해진 시각에 자동 실행) + 이메일로 대신한다.
3. 홈 화면을 만든다. 읽기 전용으로 이번 주 현황을 보여준다.
4. 통계와 달력 화면을 만든다.
5. 기록 수정·삭제 기능을 만든다.
6. 휴대폰 홈 화면에 바로가기를 추가하고, 1~2주 실제로 써본 뒤 조정한다.

## 8. 미확인 사항

- Instinct 알림이 실제로 정해진 시각에 오는지 (10/7 수 20:00 첫 확인)
- 올해(2026) 이미 완독한 책 수. 초기값으로 입력해야 한다.
