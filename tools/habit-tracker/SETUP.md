# 습관기록 웹앱 설치 (PC에서 약 10분)

## 1. 목표 탭에 기존 완독 수 넣기
"목표" 탭 D1에 `올해 기존`, D4(책 완독 줄)에 `2`를 넣는다.
올해 이 시트를 쓰기 전에 끝낸 책 수다. **내년 1월에는 0으로 바꾼다.**

## 2. 코드 붙여 넣기
1. "습관기록" 시트에서 **확장 프로그램 → Apps Script**
2. 왼쪽 `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs`를 붙여 넣는다.
3. 왼쪽 **파일 옆 + → HTML** → 이름을 `Index`로 (확장자 없이) → 내용을 지우고 `Index.html`을 붙여 넣는다.
4. 저장(Ctrl+S)

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 → **웹 앱**
3. 다음 사용자 인증 정보로 실행: **나**, 액세스 권한이 있는 사용자: **나만**
4. **배포** → 권한 승인
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**. 내가 만든 스크립트라서 나오는 정상 경고다.
5. 나오는 **웹 앱 URL**을 복사한다.

## 4. 휴대폰 홈 화면에 추가
1. 휴대폰 Chrome에서 그 URL을 연다 (시트와 같은 구글 계정으로 로그인되어 있어야 함).
2. 메뉴(⋮) → **홈 화면에 추가**

## 코드를 고친 뒤
**배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. 그래야 같은 URL에 반영된다.

## 문제가 생기면
- "기록 탭과 목표 탭이 모두 있어야 합니다": 탭 이름이 정확히 `기록`, `목표`인지 확인
- 날짜가 하루씩 어긋남: **파일 → 설정 → 시간대**가 `(GMT+09:00) 서울`인지 확인
- "목표에 없는 항목" 경고: 기록 탭의 항목 이름을 `운동`/`독서`/`책 완독`으로 고친다
