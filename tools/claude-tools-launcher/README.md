# 클로드 도구 한 번에 켜기 (Windows)

`start-claude-tools.bat`을 더블클릭하면 아래 세 도구가 각각 창으로 켜지고, 잘 켜졌는지 자동으로 확인합니다.

| 창 이름 | 도구 | 주소 |
|---|---|---|
| OmniRoute | AI 자동 전환 서버 | http://localhost:20128 |
| Headroom | 사용량 절약 프록시 | http://127.0.0.1:8787 |
| claude-mem | 작업 기억 | http://127.0.0.1:37777 |

## 사용법
1. `start-claude-tools.bat`을 바탕 화면 등 편한 곳에 두고 더블클릭합니다.
2. 확인 창에 `[ OK ]`가 세 줄 나오면 준비 완료입니다. 확인 창은 닫아도 됩니다.
3. 세 도구 창은 클로드 코드를 쓰는 동안 **닫지 마세요**.
4. 그다음 클로드 코드(cmd의 `claude` 또는 데스크톱 앱 Code 탭)를 사용합니다.

## `[FAIL]`이 나오면
해당 이름의 창에 빨간 오류가 있는지 확인하세요. 이미 켜져 있던 도구를 한 번 더 켜면 "포트 사용 중" 오류가 날 수 있는데, 이때는 먼저 켜진 쪽이 작동 중이므로 새로 뜬 창만 닫으면 됩니다.

## 컴퓨터 켤 때 자동 실행 (선택)
`Win + R` → `shell:startup` 입력 → 열린 폴더에 이 `.bat` 파일의 **바로 가기**를 넣습니다.
