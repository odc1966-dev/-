# 설치 방법 (안드로이드에서 "공유 → 원두라벨" 쓰기)

사진 공유·직접 인쇄·API 호출은 모두 **https 주소**가 필요합니다.
아래 중 하나로 이 `pwa/` 폴더를 올리면 됩니다.

## A. GitHub Pages (무료, 권장)
1. github.com → 이 저장소 → **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: `claude/coffee-bean-storage-label-mnz20l` / 폴더 `/ (root)` → Save
3. 1~2분 뒤 주소가 나옵니다: `https://odc1966-dev.github.io/-/tools/bean-label-maker/pwa/`
4. 안드로이드 **Chrome**으로 그 주소를 열고 → 메뉴(⋮) → **앱 설치 / 홈 화면에 추가**

> 설치를 해야 갤러리 공유 시트에 "원두라벨"이 나타납니다.

## B. Netlify Drop (계정 없이 30초)
app.netlify.com/drop 에 `pwa` 폴더를 끌어다 놓으면 https 주소가 즉시 생성됩니다.

# 사용 흐름

1. 갤러리에서 원두 봉투 사진 선택 → **공유 → 원두라벨**
   (앱에서 [사진 선택]·[카메라 촬영]으로 직접 넣어도 됩니다. 최대 6장)
2. 자동으로 정보 추출 → 폼과 미리보기가 채워짐
3. 확인 후 **[프린터로 인쇄]** — P15가 자동 연결되어 인쇄

"분석이 끝나면 바로 인쇄"를 켜면 2~3단계가 자동으로 이어집니다.
기본값은 꺼져 있습니다 — 인식이 틀린 채로 인쇄하면 라벨이 낭비되므로 한 번 보고 찍는 쪽을 기본으로 두었습니다.

# API 키

사진 분석은 Claude API를 씁니다. console.anthropic.com 에서 키를 발급해
앱의 **[Claude API 키 설정]** 에 넣으면 이 휴대폰에만 저장됩니다.

- 사진 1장당 대략 $0.01~0.03 (Opus 5 기준, 모델은 앱에서 변경 가능)
- 키는 브라우저 저장소에 평문으로 남습니다. **콘솔에서 사용 한도(Spend limit)를 낮게 걸어두세요.**
- 키 없이 쓰려면 **[JSON 붙여넣기]** — Claude 대화창에 사진을 올려 받은 JSON을 붙여넣으면 됩니다.

# 정확도에 대해

- 봉투에 인쇄된 정보 > 동봉 설명서 > 쇼핑몰 캡처 순으로 우선하도록 지시했습니다.
- **사진에서 확인되지 않은 항목은 비워 둡니다.** 추측해서 채우지 않습니다.
- 로스팅 날짜는 스티커·인쇄가 보일 때만 넣고, 유통기한·구매일 숫자를 날짜로 오인하지 않도록 지시했습니다.
- 그래도 오인식은 발생할 수 있으니 인쇄 전에 미리보기를 확인하세요.
